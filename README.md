# AssReg

AssReg (Asset Registry) is an application designed to help organizations track and manage their IT assets, including computers and connected devices like monitors.

## Features

- **Asset Tracking**: Record and maintain a comprehensive inventory of all IT assets, by ensuring information up to date and with no duplication.
- **Asset Details**: Store important information about each asset (serial numbers, specifications, location, etc.)
- **Remote Data Transfer**: You can easily send captured information on a computer to remote computer running AssReg as Server.
- **CSV/Excel Support**: Data is stored in both csv and excel to allow further processing.
